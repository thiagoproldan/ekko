## Notes

### <a id="154"></a>154. Measured 2026-09-14 with the installed release binary. reaches() recurses through blockers with no record of what it…

Measured 2026-09-14 with the installed release binary. reaches() recurses through blockers with no record of what it has already visited, so it enumerates paths rather than items. A chain of L diamonds has 2^L paths from bottom to top, and an added dependency that is not a cycle has to exhaust every one of them before it is accepted. Times for a single --blocked-by: L=20 (62 tasks) 217 ms, L=22 792 ms, L=24 3.2 s, L=26 (80 tasks) 12.5 s. Every step inside it is also a linear scan to find an item by uid. The real boards are nowhere near this -- the longest chain on any of them is 5, on winwayland -- so nobody has felt it, but a mathematical backend cannot keep an exponential step: a visited set makes the same check linear in items plus edges, and an index from uid to item removes the scans. Tarjan or Pearce-Kelly are not needed at this scale; they matter for large graphs taking many insertions.
