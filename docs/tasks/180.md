Next, the user typed /reume (an unknown command) and went back with /resume to the old session, which re-sends the long transcript, the very cost the handoff exists to avoid. The procedure to state wherever the handoff is explained: /clear, then any message ('continua'), or start fresh with claude "continua" from the project folder. A candidate fix: the handoff prompt's last line (src/agent.rs, handoff_prompt) says 'tell the user it is safe to /clear' and could add 'then send any message; the session starts on it'.
