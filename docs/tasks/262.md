# 262. When several sessions hand off, the prime shows every handoff under an hour old on open work, each with its task and…

*Task · done · medium priority · created 2026-09-21 · [history](../history.md)*

When several sessions hand off, the prime shows every handoff under an hour old on open work, each with its task and time, and the newest in full, instead of only the newest. Today 'Where the last session stopped' is the newest handoff on the whole board, so a /clear can resume the other session's task, and a bare 'continue' (decision [227](../decisions.md#227)) then works a task another session still holds. The handoff prompt should also tell the user to send 'continue &lt;id>' after /clear. From the multi-session review, 2026-09-21.
