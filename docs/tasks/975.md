# 975. ctx: a session alone is asked for a handoff that auto-reset then cannot type

*Task · done · created 2026-09-30 · [history](../history.md)*

The Stop hook reads a session as alone from the Konsole variables, the cli entrypoint, a claude ancestor and the idle time. It never checks what auto-reset checks first: that the tab's foreground process is this session's Claude Code.

So a session whose tab shows something else is held for a handoff, and then auto-reset stops at start and nothing clears the session. A background job is one such session.

Measured in \~/.local/state/ctx/handoff.jsonl: 4 of 13 auto-reset starts ended at start that way, on 2026-09-27 20:01Z and 21:32Z, 2026-09-28 01:15Z and 2026-09-30 03:04Z. The last was this session, a background job, asked at 274k by ctx 0.9.0's hook. ctx 0.10.1's alone test has the same gap.

Fix: add ctx_konsole_foreground equal to Claude Code's pid (lib/konsole.sh) to the alone conditions in hooks/handoff. It is one D-Bus call, made only past the threshold. The test needs a tab whose foreground is another process: the fake tab's FG, which test a3 already uses.
