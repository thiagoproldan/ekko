*Task · done · medium priority · created 2026-09-22 · [history](../history.md)*

A batch's text that holds $N is kept as written, with nothing said: the reply could name it. SEEN 2026-09-22, session e3011485: an edit inside a batch appended 'task $2', meant as the task the batch's second operation created, and the note kept '$2' until a second edit fixed it. By design, since prose may mean a dollar sign (note [335](312.md#335): batch leaves $1 in text alone); and $N misleads another way too (note [392](../notes.md#392) (2): it names the item operation N created, not the Nth item created). FIX: when the text of a create or an edit in a batch holds $N for an N the batch defines, the reply carries a notice -- 'operation 3's text holds $2, which batch does not replace: that item is 394' -- and the text is left as it is. From the retrieval check in note [399](../notes.md#399).
