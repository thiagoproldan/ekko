# 283. prime(if_rev) and next(if_rev) answer 'unchanged' across midnight while the order and the overdue list moved

*Task · done · created 2026-09-21 · [history](../history.md)*

urgency uses today for the due ramp and the age term, and the prime lists overdue work against today, but unchanged() in src/mcp.rs compares only the revision. After midnight a task can become overdue, or move up next, with no write at all. Fix: keep the day beside each cursor the server hands out, or answer in full when the day changed since that cursor's read.
