### <a id="506"></a>506. Who writes the trailer? Either way, context lists the commits naming the item, read from git when asked, nothing…

Who writes the trailer? Either way, context lists the commits naming the item, read from git when asked, nothing stored: those on the current branch, then those only on other branches. A rebase, cherry-pick or squash keeps the line, so the link survives a new SHA.

Options:

- The agent, told when it takes a task (Recommended): When a task enters progress in a git repo, the reply says once that its commits end with 'Ekko: &lt;id>'. Nothing installed; later commits follow the repo's style.
- A hook that stops a commit without it: A PreToolUse hook on git commit while the session holds a task, once per commit: deterministic, but it interrupts commits that are not the task's.
- A git commit-msg hook that adds it: Hands-free, but installed per repo, and it collides with repos that have hooks of their own.

**Answer**, 2026-09-24: The agent, told when it takes a task (Recommended)
