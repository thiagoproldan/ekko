# 805. ekko: a gotcha with a command cue refuses the calls it names

*Task · done · created 2026-09-26 · [history](../history.md)*

Decision [801](../decisions.md#801) (task [770](770.md)); it revives note [402](337.md#402)'s item (1), which decision [587](../decisions.md#587) deferred. A gotcha may carry a cue: a command, words its arguments must hold, and optionally a folder. A PreToolUse hook (ekko --guard --hook) matches the cue against the calls a command parses into, never its text, so a heredoc or a memory file that names the call passes. It refuses with the gotcha's text as the reason.

- Only the user can set, change or drop a cue. A session can propose one, which stays off until the user turns it on.
- Exceptions: a question answered by a person that quotes the exact command lets the next identical call through once. ctx's guards consult the same check.
- First cues: the GitHub Project Status field (a gh api graphql call holding updateProjectV2Field, the incident of 2026-08-20 in note 797) and cargo fmt --all in winwayland. The pgrep guard stays in \~/NixOS.

## Notes

### <a id="821"></a>821. Como você liga uma trava que uma sessão propõe?

A sessão escreve a trava na gotcha, mas ela fica desligada até você aprovar; mudar ou remover uma trava ligada também volta a depender de você.

Como outras ferramentas fazem:

- direnv: só roda um .envrc depois de `direnv allow` no terminal, e qualquer mudança no arquivo revoga a aprovação.
- dcg: o humano roda `dcg allowlist add`, e o dcg bloqueia o agente que tenta o mesmo comando.
- Codex: a confiança num hook é dada na interface do próprio Codex.

Options:

- Pelo menu do ekko (Recomendado): A sessão propõe pelo ask; o menu mostra a gotcha, o comando, as palavras e a pasta, e sua resposta 'Ligar' liga. É o mesmo canal da exceção, sem nada para digitar. Mudou a trava, volta a pedir.
- Só no terminal: Você digita `ekko --cue <id> on`, como no `direnv allow`. O ekko recusa quando quem roda é uma sessão, pela árvore de processos.
- Os dois: O menu para as propostas das sessões e o terminal para quando você mesmo quiser ligar, mudar ou desligar uma trava.

**Answer**, 2026-09-26: Pelo menu do ekko (Recomendado)

### <a id="822"></a>822. Como a exceção se prende ao comando?

Já decidido (801): vale uma vez, para o comando exato, e só com resposta sua. Falta o formato.

O dcg faz assim: a recusa gera um código curto, preso ao comando exato e à pasta; o humano roda `dcg allow-once <código>`; a exceção vale uma vez e expira em 24h.

Pela documentação do Claude Code, uma recusa do ctx vence qualquer liberação do ekko. Então o ctx consulta o ekko antes de recusar, e só nesse caminho: as outras chamadas não pagam nada.

Options:

- Código da recusa (Recomendado): A recusa (do ekko ou do ctx) grava a chamada exata e a pasta sob um código e diz ao agente para pedir pelo ask com esse código. O menu mostra o comando e a pasta do registro, não o texto do agente. 'Liberar uma vez' solta a próxima chamada idêntica, na mesma pasta e da sessão que pediu, em até 24h. O uso fica gravado na pergunta.
- Comando citado pelo agente: O agente copia o comando no ask e o ekko compara o texto. É mais simples, mas um comando longo copiado com um caractere diferente não casa, e você aprova a cópia do agente, não a chamada recusada.

**Answer**, 2026-09-26: Código da recusa (Recomendado)
