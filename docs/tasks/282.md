# 282. create with attached_to and no kind should make a note: a task can never be attached, and the refusal costs a call

*Task · done · created 2026-09-21 · [history](../history.md)*

Gotcha [245](../gotchas.md#245) documents the trap. In the transcripts since 2026-09-15, 2 of 75 creates were refused ATTACH_NOT_A_NOTE, each a wasted call of \~30k units at this context size. With attached_to given and kind absent, the only valid reading is a note; a create without attached_to keeps defaulting to task.
