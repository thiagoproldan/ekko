prime can pass the 10,000 characters Claude Code keeps: Needs attention lists every overdue, broken, inverted and cancelled-freed item, outside the budget

Measured 2026-09-21 on synthetic boards (target/evals/analise-final/scripts/overflow.py): 1,000 overdue tasks give a 5,809-character prime that is almost all the 'overdue: 1, 2, ...' line, with the ready and blocked work cut; 2,000 give 11,057 characters; 5,000 give 29,057, so the SessionStart hook hands the session a 2 KB preview. Prime::text_within puts attention() in the fixed part, and the room left saturates at zero, so the budget cannot hold it. Fix: cap each attention list at about ten ids with '+N more: search with the overdue filter' (or blocked), inside the budget. Minor, same function: a '+N more' line with N of 1,000 or more is 49 to 50 characters against the 48 reserved per section (MORE_LINE). Acceptance: the prime stays within 6,000 characters plus the handoff section on a board with 5,000 overdue tasks.
