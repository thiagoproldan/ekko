# 469. The replaced-binary note (274) never fires under the Nix-built plugin. The flake has pinned the plugin's command to its…

*Task · done · medium priority · created 2026-09-23 · [history](../history.md)*

The replaced-binary note (274) never fires under the Nix-built plugin. The flake has pinned the plugin's command to its store path since 35e36e5 (v0.7.1), before 274 (3e4b41a). A server started as /nix/store/…-ekko-0.15.0/bin/ekko resolves its argv[0] to itself, so Server::replaced() stays false for good. Seen 2026-09-23: after the 0.16.0 rebuild the user ran /clear, not a restart. The process's two servers (pids 706249, 706261) stayed on 0.15.0, and no reply carried the note. Fix to weigh: also watch the `ekko` on PATH when, at start, it led to this same binary (true for the Nix profile and for cargo install). A dev build started by its path, beside an older ekko on PATH, is then left alone.
