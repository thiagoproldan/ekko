# 967. ctx: auto-reset typed /clear into a draft the user was writing

*Task · done · medium priority · created 2026-09-29 · [history](../history.md)*

Found 2026-09-29 by task [941](941.md)'s recount, in session 2ff25d1b (nakaya-shell, default profile, Claude Code 2.1.284).

What happened:

- 16:52:20Z: the user sent 'pode continuar, até os 100%'. While that turn ran, they typed their next question into the input box.
- 17:02:08Z: the Stop hook asked for the handoff.
- 17:02:52Z: the turn ended, 10 minutes after the last sent prompt. So the hook read the user as away (CTX_AUTO_RESET_IDLE 10) and, the handoff being fresh, started bin/auto-reset.
- The box held the draft 'o teste que vc rodou agora é o resultado esperado?', unchanged over two readings. auto-reset takes such text for a possible prompt suggestion. It typed '/clear', saw it appended, and began taking it back: six backspaces 0.15 s apart, with no check between them (press(), src/bin/auto-reset).
- 17:02:53.753Z: the user pressed Enter midway. The prompt went out as '...esperado?/clea'. The ledger says 'taken back' anyway.

Three faults:

1. Away is read from the last sent prompt. A user who watches a turn longer than CTX_AUTO_RESET_IDLE counts as away at its end.
2. Text stable over two readings is typed into, and a paused draft is stable too.
3. The take-back does not check the box between backspaces, and logs 'taken back' whatever happened.

Since 0.10.0 the same path also asks for the handoff: a watched turn longer than 10 minutes, past the threshold, gets the ask task [961](961.md) took away from a user who is there.

Record in \~/.local/state/ctx/handoff.jsonl: 12 auto-reset starts, 8 resets, 4 stops. Three stopped at start because the tab's foreground process was not the session's Claude Code; the fourth is this one.

The fix is the user's call. Options:

- read away from the end of the last turn the user saw, not from the last prompt;
- never type into a box that holds text (with promptSuggestionEnabled false, any text there is the user's);
- check the box before each backspace.
