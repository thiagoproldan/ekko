### <a id="986"></a>986. O guard de gotchas vale as \~2.300 linhas que custa, com 1 cue em uso?

Explanation: Um gotcha pode ter um cue: uma regra que o ekko checa antes de cada comando Bash do agente e que recusa o comando citando o gotcha como motivo (ex.: recusar 'cargo fmt --all' no winwayland). Isso custa guard.rs + shell.rs, \~2.300 linhas (12% do código), e \~2 ms por comando Bash. Hoje há 1 cue ligado, só no board do ekko, e nenhum em projeto real. O Claude Code já tem um bloqueio nativo e documentado: permissions.deny nas settings.

Options:

- Manter
- Remover e usar permissions.deny (recommended)
- Congelar
