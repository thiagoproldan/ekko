### <a id="136"></a>136. 113 and 114 are fixed in c472d3c and still open only because nobody confirmed it: the session that shipped the fix…

113 and 114 are fixed in c472d3c and still open only because nobody confirmed it: the session that shipped the fix asked the user whether to close them or to test first, and ended without an answer. What to look for when testing. Enter and Tab refuse a done or cancelled task with "21 is finished -- use --set to change it", so a stray key can no longer undo a terminal state. And every write made from the UI says what it did, in place of the status line for a moment, as "21 → done" or "21 stashed". Once tried, closing both is one --set.

ADDENDUM 2026-09-21: the --ui was rebuilt as the dashboard (5956589, 2026-09-15) and the keys above changed; the fix survived the rebuild. Tab now only moves focus between regions and never writes. In the board list, Enter completes, Space starts or pauses, and Ctrl+S stashes (src/tui/app.rs:820-835). A done or cancelled task refuses every key with 'N is finished; change it from the CLI with --set' (app.rs:1393), and every write or refusal flashes on screen and is logged with its time in the panel's Output tab (Ctrl+J shows the panel). Tests in src/tui/app.rs cover it: a_finished_task_stays_finished_whatever_is_pressed, space_starts_a_task_and_pauses_it_again, a_blocked_task_is_refused_and_never_forced. To confirm with the user: in ekko --ui, press Enter and Space on a done task (refused, state unchanged); then press Space twice on a scratch task made for the check ('N in progress', then 'N paused', both in Output) and remove it after. If both hold, set 113 and 114 done.
